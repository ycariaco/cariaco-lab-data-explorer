Methods and statistical benchmark

Cariaco Lab Data Explorer · Version 1.0.1 · Updated 18 September 2026

Intended for exploratory use. The application helps visualize, screen, and summarize data. It does not replace a prespecified analysis plan or review in specialist statistical software.

What was checked

The browser calculations were run on fixed reference datasets and compared with R 4.6.1 using base R, car 3.1-5, nlme 3.1-169, and rstatix 1.1.0. Of 97 numerical comparisons, 93 agreed within the declared tolerance. Two Shapiro–Wilk values differed modestly, and the two D'Agostino–Pearson values did not have an independently installed R reference.

Assumptions to review

  • Rows missing a selected variable are excluded from that analysis.
  • Tests are two-sided unless explicitly stated otherwise; diagnostic labels use α = 0.05.
  • Normality tests use available residuals. A non-significant result does not prove normality.
  • Outlier procedures flag observations but never remove them automatically.
  • Pairwise post-tests are simple comparisons, not estimated-marginal-means contrasts.
  • Volcano plots visualize user-supplied effects and p/FDR values; they do not fit an omics model.

How the application was made

It is a static React and TypeScript application built with Vite. Data and calculations remain in the visitor's browser; no ChatGPT, OpenAI API, database, or application server is required. Charts are rendered in the browser, while the two normality routines are supplied by a WebAssembly statistics library.
